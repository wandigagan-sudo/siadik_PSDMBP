URL Web App produksi sudah tertanam langsung sebagai default aplikasi.

Cara Update Code.gs Tanpa Ganti URL

  1. Klik tombol Salin Skrip Code.gs di sebelah kanan.
  2. Buka editor Google Apps Script proyek SIADIK Anda, tempel kode (pertahankan nilai ROOT_FOLDER_ID bila ada), lalu tekan Ctrl + S.
  3. Klik Deploy → Manage deployments → ikon Edit (Pensil).
  4. Ubah Version menjadi New version, lalu klik Deploy. URL Web App tetap sama dan seluruh fitur baru langsung aktif!
